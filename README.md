# Beyond: Craftlines / 超越维度：合成链

[English](README_EN.md) | **简体中文**

面向 Beyond Dimensions 的配方驱动自动合成系统。Beyond: Craftlines 将 JEI 中的配方展开为可交互的递归合成树，从 BD 网络统一预留原料、调度工作台与真实机器、回收产物，并以可追踪、可取消、可持久化的订单完成从“查到配方”到“拿到成品”的整条生产链。

## 核心功能

- **从 JEI 或网络直接下单**：从 JEI 配方页面打开时，后台自动规划保持入口所选根配方，玩家仍可手动切换根配方并按新选择重新计算；从 BD 网络物品槽中键打开时，根节点优先使用玩家保存的配方偏好，没有有效偏好才回退到首个可用候选。第一阶段按配置的每 tick 条目上限建立并缓存配方查找索引，完成后一次性显示完整树；第二阶段保持树形布局不变并继续准备规划目录。两级缓存仅在配方重载后失效，重复打开无需重新索引。
- **清晰的合成树与原料统计**：EMI 风格的自上而下树形界面会合并同层重复材料，提供配方预览、候选原料选择、缺料高亮，以及理论用量、实际网络提取量和余料视图。
- **客户端预览、服务端下单校验**：客户端基于服务端签发的版本化库存快照完成候选搜索、取料和缺料预览；点击下单后，服务端以最新库存沿固定选择线性复算，缺少任一材料便报错且不创建订单。
- **Beyond Dimensions 网络执行**：订单直接从对应 BD 网络预留和提取资源，支持正 `long` 数量；同一网络按 FIFO 尝试执行，非普通合成配方类型无交集的订单可并行，机器拒收的余量会安全退回网络。
- **订单内并行调度**：同一订单中依赖已经满足的配方步骤可同时推进；不同机器可以并行工作，同一维度坐标上的机器仍严格互斥。
- **真实配方与容器语义**：工作台步骤调用服务端原始配方逻辑，保留动态组件、耐久工具、容器返还物以及模组自定义的 `assemble` 和剩余物行为。
- **配方机器自动化**：使用网络连接器绑定或解绑原版及第三方机器；BD 网络组件除外。Craftlines 根据 JEI 催化剂与服务端 `RecipeType` 建立确定性映射，并通过机器真实能力投料、检测产出和执行回滚，不依赖针对特定科技模组的硬编码分支。
- **原生网络熔炉支持**：Beyond Dimensions 的网络熔炉、网络高炉和网络烟熏炉无需手动绑定；Craftlines 会在同一网络中寻找空闲设备，投送输入并等待真实产物返回网络。
- **可控的批次调度**：AE2 风格阻挡模式会等待上一批完成并回收后再发送下一批，适用于容易串配方或内部仍有残留输入的机器。
- **通用自增配方**：产物同时作为输入且净产出为正时，配方树只取用一次所需的最小种子，并按净增量展开其它原料；真实机器会自动逐轮投料。
- **合成链供给器**：供给器可按所绑定机器支持的配方类型接收订单产物，并允许外部管道提取；也可用网络连接器无线连接目标设备的指定面，同一设备可分别设置一个直接供应面和一个在本供给器参与请求期间直抽到网络的抽取面。供应可按轮询、最近优先或最远优先执行。每个供给器默认最多连接 16 台不同设备（服务端可配置），配置界面、Jade、世界高亮和编辑态连线会显示连接状态。
- **合成链仪表盘**：薄面板可附着在容器或网络设备表面，通过 JEI ghost ingredient 槽标记物品、流体或化学品，并保存维持数量、网络/容器监测模式、红石模式、阻挡模式和固定配方树。仪表盘按配置周期补足缺口；自动订单不占玩家订单上限，每个网络默认最多同时存在 10 个。
- **持久化订单与状态管理**：订单、步骤进度和机器绑定会随世界保存；玩家可以查看网络订单、诊断等待原因并取消尚未完成的任务。

## 支持版本

- Minecraft 1.20.1 / Forge 47 / Java 17
- Minecraft 1.21.1 / NeoForge 21.1 / Java 21
- Minecraft 26.1.2 / NeoForge 26.1.2 / Java 25

除非明确限定版本，功能说明和开发改动均适用于以上三个版本。

- `mod_id`: `beyond_craftlines`
- 必需依赖：Beyond Dimensions、JEI
- 可选依赖：GuideME（安装后提供中英文详细指南；悬停网络连接器或合成链供给器并按住 G 可直达对应页面）

本模组只负责下单系统：JEI 配方页入口、EMI 风格递归配方树、AE2/RS 风格订单确认、BD 网络扣料与合成、原版及第三方机器配方类型绑定、订单持久化/状态/取消，以及可配置配方类型的合成链供给器。

构象捕获、沙盒试产、报告、稳态产线与图纸复制已经迁移到独立模组 `Sky Logistics: Linefold`，本模组不再注册任何构象方块、物品、命令、维度或 SavedData。

## 构建

未明确限定版本时，改动、验证与打包均同时覆盖三个支持版本。分别使用 Java 17、21、25 执行：

```bash
# Minecraft 1.20.1 / Forge
cd versions/1.20.1 && ../../gradlew --no-daemon build

# Minecraft 1.21.1 / NeoForge（从项目根目录执行）
cd ../.. && ./gradlew --no-daemon build

# Minecraft 26.1.2 / NeoForge
cd versions/26.1.2 && ../../gradlew --no-daemon build
```

三个产物分别位于：

- `versions/1.20.1/build/libs/beyond_craftlines-0.4.0+1.20.1.jar`
- `build/libs/beyond_craftlines-0.4.0+1.21.1.jar`
- `versions/26.1.2/build/libs/beyond_craftlines-0.4.0+26.1.2.jar`

## 使用概要

1. 在 JEI 配方查询页点击 Craftlines 入口，或在 JEI 配方槽、物品列表、书签列表中键目标资源，确认递归配方树与数量后下单；按钮入口的后台自动规划保持当前 JEI 根配方，玩家可手动切换根配方并按新选择重新计算；中键入口则与 BD 网络物品槽一致，优先使用已保存的根配方偏好。树采用 EMI 风格的自上而下布局，目标产物在上、原料逐层向下展开，同一配方层内的相同物品会合并并累计数量；默认只完整显示同一组件资源键最靠近树根的一次，后续更深层位置显示可点击跳转引用，此显示折叠可由客户端配置关闭。悬浮可查看所选配方的原料 → 产物图形预览、配方族和 ID。右侧原料汇总采用 EMI 风格的图标网格与数量叠字，可切换理论总计、实际网络提取和余料；规划缺料时立即改为红色缺料网格。点击 tag/OR ingredient 节点会打开完整候选物品网格供直接选择，右击配方节点可打开生产配方候选；已经保存偏好时，候选页右上角会显示“遗忘偏好”按钮。玩家已保存的配方与原料偏好优先于自动建议；客户端候选搜索最多持续约 3 秒，节点或时间预算耗尽后不再尝试新的可制造方案，只完成当前配方树的固定选择验证。
2. 网络连接器右击原版或第三方机器进行绑定，潜行右击解绑；手持连接器左击已绑定机器可打开配方类型配置界面。该实验版只使用 JEI category UID 和 JEI 当前布局生成临时配方，不读取服务端 `RecipeType` 映射或分类白名单。JEI runtime 会把可解析布局建立为有界递归候选目录，提交时只分页上传本次树实际选择的描述。JEI 输入 slot name 会规范化为材料子标签：`catalyst` 等语义名称保持独立，`input_0` 等普通编号槽合并为 `ingredients`。铁砧、酿造台、堆肥桶、锻造台和切石机仍只能走供给器。
3. 外部机器按真实能力投料和收取产物，不内置 Mekanism 或其他具体模组分支。
4. BD 网络熔炉、网络高炉和网络烟熏炉无需绑定；订单直接向同网络的空闲对应炉型投料，并等待真实产物回网。
5. 同一 BD 网络的订单由 Craftlines 按 FIFO 尝试取得库存事务权；订单全部非普通合成配方类型与本 tick 已执行订单无交集，且未达到 `crafting.maxConcurrentOrdersPerNetwork`（默认 4）时可继续执行。普通合成 `crafting` 不计入冲突。取得执行权的订单会并行推进所有依赖已满足的步骤；不同机器可同时加工，同一机器一次只分派一个步骤，机器拒收的余量自动退回网络。将该配置设为 1 可恢复严格串行。
6. 下单时可开启 AE2 风格阻挡模式：每次只推送一次配方输入，上一批完成并回收后才发送下一批；目标机器预存本配方输入时也会等待。
7. 合成链供给器只接受订单产生的资源，不能由管道写入；右击可随时打开配置界面，手持连接器左击也可打开。配方类型绑定完成后，用连接器右击供给器进入无线绑定模式；普通右击设备目标面设置或移动供应面，潜行右击设置或移动抽取面，对已绑定面重复对应操作会断开该角色的连接。同一设备可同时拥有一个供应面和一个抽取面，且在默认 16 台设备上限中仍只计为一台。编辑时供应面及其与供给器之间的连线为蓝色，抽取面及连线为深橙色，准星候选面为黄色；退出编辑后所有连接面统一显示持续的蓝黑超维像素边框。客户端 `binding.showProvisionerBoundFaceFrames` 可单独关闭这些无线绑定面边框，不影响 `binding.showBoundMachineFrames` 控制的直接绑定机器边框，也不影响编辑态彩色高亮与连线。抽取面仅在该供给器实际参与当前合成请求期间从目标面的能力直接抽入 BD 网络，不经过供给器库存。GUI 计数显示“供应：x，抽取：y”，其右侧单按钮循环切换轮询、最近优先和最远优先；默认开启的服务端配置 `provisioner.resetRoundRobinOnRecipeActivation` 会让轮询在每次独立配方请求激活时从第一条绑定开始，阻挡模式则每轮从头开始，关闭后恢复跨请求连续轮询。某供应目标拒收当前资源时会继续尝试下一个目标。Jade 显示同样的双计数。清空供给器的配方类型时会同时清空全部设备连接。原有的潜行右击供给器后扫描目标机器仍用于建立配方候选；编辑模式外潜行右击目标机器仍用于解除直接绑定。配方类型与材料组选择、侧面目标图标、外部管道提取及“全部送回网络”功能保持不变。
8. 工作台配方统一通过服务端原配方模拟，保留动态组件、耐久工具、容器返还物和模组自定义 `assemble/getRemainingItems` 行为。相同 BD 组件键的稳定输入会按可用数量一次批量结算；会改变耐久或组件的工具才逐次推进。订单数量使用正 `long`，最大支持 `Long.MAX_VALUE`。
9. 配方候选搜索、库存抵扣与缺料汇总使用服务端签发的版本化库存快照在客户端后台完成；点击下单后，服务端才以最新库存对固定选择做线性复算，缺少任一材料时拒绝且不创建订单。订单产物默认存入 BD 网络，也可在数量区下方轮切为存入玩家物品栏；该选择由客户端记忆。
