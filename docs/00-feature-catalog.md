# 00 · 全部功能一览

本文是 Beyond: Craftlines（`beyond_craftlines`，中文名「超越维度：合成链」）的**最终功能全集**。不按 MVP 裁剪。

---

## A. 身份与依赖

- 英文显示名：`Beyond: Craftlines`
- 中文显示名：`超越维度：合成链`
- 模组 ID：`beyond_craftlines`
- 创意标签：`itemGroup.beyond_craftlines`
- 硬依赖：Beyond Dimensions
- 软依赖：Sky Logistics、JEI、Jade（**无 EMI 联动**）
- 支持版本轨：
  - `versions/1.20.1`（Forge）
  - `versions/1.21.1`（NeoForge）
  - `versions/26.1.2`（NeoForge）
- 共享代码：`common/`（对齐天穹物流 `common + versions/*`）

## C. BD 维度网络界面下的 JEI 下单与配方树

> 关键约束：**只有玩家打开超越维度的维度网络界面时**，在 JEI 查询配方才会出现 Craftlines 额外按钮；不是全局 JEI 常驻按钮，也不是快捷键入口。

### C1. 下单入口（最终态）

1. **JEI 额外按钮**：仅当当前打开的是 BD 维度网络相关 GUI（终端/网络界面）时出现  
   - `预览配方树`  
   - `下单`（执行）
2. **鼠标中键**：在维度网络界面的物品列表上，中键点击某个物品/已标记产物，直接进入该物品的下单/配方树界面  
3. **不做**独立快捷键打开下单界面  
4. **不做 EMI 联动入口**（可学习 EMI 配方树视觉，但不集成 EMI 插件/按钮）

### C2. 网络界面中的稳态构象图产物标记

- 当 BD 维度网络库存中的某个物品，可由至少一张**稳态构象图**产出时，在网络物品格子上显示特殊标记（角标/描边/小图标）
- Tooltip 追加：可用构象图名称、预估输入摘要、点击/中键可下单
- 标记只在维度网络界面渲染，不污染普通物品栏

### C3. 配方树预览（学习 EMI 风格，非 EMI 联动）

- 界面风格对齐 EMI Recipe Tree / BoMScreen：画布树、缩放拖拽、批次、底部成本条、折叠与替代解析
- 详见 `15-ui-recipe-tree-emi-style.md`
- 递归展开前置配方
- 节点状态：网络已有 / 需合成 / 构象图黑盒 / 缺料
- 替代配方切换、重复次数、产物去向（网络/背包，记忆）
- 循环依赖与深度限制提示

### C4. 下单执行

- 按整棵树调度，而非只 fill 合成格
- 材料预留/扣费/退款账本
- 中间产物回网络
- 可并行无依赖节点
- 可取消、可超时、可进度查询
- 同输入槽单一物品变体策略

### C5. 默认可执行配方族

- 原版合成（有序/无序）
- BD 网络熔炉 / 高炉 / 烟熏炉
- 数据包可扩展 `RecipeFamily`
- 外部模组机器自动执行默认关闭，需显式执行器 + 配置开启

### C6. 稳态构象图作为缺料来源

- 输出匹配时可作为工作树节点
- 嵌套执行构象图黑盒
- 防环与嵌套深度限制

## D. 设备绑定功能

- 时空联结器潜行右键绑定/解绑
- 手持右键空气打开绑定管理（不是快捷键下单）
- 绑定记录：网络、维度、坐标、设备类型、配方族、昵称、收藏
- 绑定管理：搜索、状态、远程打开 GUI（若支持）、解绑、批量清理失效
- 附近扫描绑定（仅已加载区块，不强加载；由联结器界面触发）
- 领地权限检查（FTB Chunks / Cadmus 等软探测）
- 方块破坏惰性清理
- 外部设备绑定默认只提供管理/远程 GUI；自动执行需 `DeviceExecutor`

## E. 产线图纸生命周期

### E1. 框选与捕获

- 类结构方块的角点/尺寸模式
- 体积上限与危险方块黑名单
- 捕获方块态、BE NBT、初始容器/流体/能量
- 捕获天穹节点配置（若存在）
- 生成未稳构象图（物品引用 + 服务器库存储）

### E2. 沙盒测试

- 粘贴到测试维隔离槽
- 使用原版屏障包围
- 玩家以观察者模式进入查看
- **不提供专用退出按钮**；若玩家离开产线包围盒范围持续 5 秒，自动结束观察并送回原位置/模式
- 也可在锚点/会话 GUI 中“停止试产”（这是停止测试，不是观察者退出按钮）
- 手动停止 / 超时 / 稳态窗口结束
- 退出后还原玩家状态，禁止带出测试产物

### E3. 计量与报告

- 内容器/流体/能量差分
- 天穹跨界进出计量（核心）
- 报告：耗材 CAPEX、运行输入、运行输出、净能量、周期估计、警告
- 玩家确认后编译

### E4. 编译产物

- `stabilized_schematic` 锁定：
  - 结构哈希
  - 耗材清单（方块 + 初始库存）
  - 材料消耗
  - 材料产出
  - 周期 tick
  - 版本号

### E5. 量产与复制

- 合成链驱动核：扣输入 → 等待周期 → 吐输出
- 模式：定时 / 红石门控 / 创意瞬发
- 并行度升级
- 构象复制台：按 CAPEX 从 BD 网络扣料复制稳态构象图

## F. 天穹物流联动功能

- 测试维节点默认允许与原维同线路跨维传输
