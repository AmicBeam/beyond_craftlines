# 00 · 全部功能一览

本文是 Beyond: Craftlines（`beyond_craftlines`，中文名「超越维度：合成链」）的**最终功能全集**。不按 MVP 裁剪。

---

## A. 身份与依赖

- 英文显示名：`Beyond: Craftlines`
- 中文显示名：`超越维度：合成链`
- 模组 ID：`beyond_craftlines`
- 创意标签：`itemGroup.beyond_craftlines`
- 硬依赖：Beyond Dimensions
- 软依赖：Sky Logistics、JEI、EMI、Jade
- 支持版本轨：
  - `versions/1.20.1`（Forge）
  - `versions/1.21.1`（NeoForge）
  - `versions/26.1.2`（NeoForge）
- 共享代码：`common/`（对齐天穹物流 `common + versions/*`）

## B. 内容物

### B1. 方块

| ID | 中文 | 功能摘要 |
| --- | --- | --- |
| `blueprint_anchor` | 产线框选锚点 | 设角点/尺寸、保存草稿、发起测试、查看报告入口 |
| `blueprint_drive` | 图纸驱动器 | 放入已编译图纸，按网络库存自动执行产线 IO |
| `blueprint_duplicator` | 图纸复制台 | 按耗材清单复制已编译图纸 |
| `test_barrier` | 测试屏障 | 仅测试维生成的技术方块，不可创造获取 |
| `sandbox_gateway`（可选最终态） | 沙盒观测门 | 从原维稳定传送到测试槽观察位；也可用锚点 GUI 代替 |

### B2. 物品

| ID | 中文 | 功能摘要 |
| --- | --- | --- |
| `dimension_tool` | 维度工具 | 绑定/解绑设备、打开绑定管理、扫描附近可绑定设备 |
| `blueprint_draft` | 未测试图纸 | 持有结构引用与初始态；可启动测试 |
| `blueprint_compiled` | 已编译图纸 | 含耗材/输入/输出/周期；可驱动、可复制、可作 JEI 来源 |
| `blueprint_report` | 产线报告单 | 测试结果实体化物品；可签核编译（也可只在 GUI 内确认） |

### B3. 菜单 / 屏幕

- 锚点配置界面
- 绑定管理界面
- 工作树预览界面（含替代配方、重复次数、产物去向）
- 合成进度 HUD / 进度界面
- 测试报告界面
- 图纸驱动器界面
- 图纸复制台界面
- （可选）沙盒观测 HUD

### B4. 命令

- `/beyond_craftlines cancel`：取消当前合成链
- `/beyond_craftlines test <blueprintId>`：启动测试
- `/beyond_craftlines stop_test <sessionId>`：停止测试并出报告
- `/beyond_craftlines debug ...`：权限 2 诊断（绑定、账本、沙盒槽位、计量）

### B5. 世界/维度

- 维度：`beyond_craftlines:sandbox`
- 单测试维多隔离槽位分配器
- 测试区屏障盒与观察者会话

## C. JEI / EMI / BD 界面功能

### C1. 入口按钮

- 在 JEI 配方页显示 Craftlines 按钮：`预览工作树`、`执行`
- 在 BD 终端/合成终端叠加同等入口
- EMI 对等入口（软依赖）
- 仅当能解析到玩家可用 `DimensionsNet` 时启用

### C2. 工作树预览（EMI 风格配方树）

- **界面风格对齐 EMI Recipe Tree / BoMScreen**（画布树、缩放拖拽、批次、底部成本条、折叠与替代解析）
- 详见 `15-ui-recipe-tree-emi-style.md`
- 递归展开前置配方
- 显示节点状态：网络已有 / 需合成 / 图纸黑盒 / 缺料
- 替代配方切换
- 重复次数调整
- 产物去向：BD 网络 / 玩家背包（记忆上次选择）
- 缩放、拖拽、折叠、缺料收藏到 JEI
- 循环依赖检测与深度限制提示

### C3. 一键执行

- 按图调度执行，而非只 fill 合成格
- 材料预留/扣费/退款账本
- 中间产物回网络
- 可并行无依赖节点
- 可取消、可超时、可进度查询
- 同输入槽单一物品变体策略

### C4. 默认可执行配方族

- 原版合成（有序/无序）
- BD 网络熔炉 / 高炉 / 烟熏炉
- 数据包可扩展 `RecipeFamily`
- 外部模组机器自动执行默认关闭，需显式执行器 + 配置开启

### C5. 图纸作为缺料来源

- 已编译图纸输出匹配目标时，可作为工作树节点
- 嵌套执行图纸黑盒
- 防环与嵌套深度限制

## D. 设备绑定功能

- 维度工具潜行右键绑定/解绑
- 绑定记录：网络、维度、坐标、设备类型、配方族、昵称、收藏
- 绑定管理：搜索、状态、远程打开 GUI（若支持）、解绑、批量清理失效
- 附近扫描绑定（仅已加载区块，不强加载）
- 领地权限检查（FTB Chunks / Cadmus 等软探测）
- 方块破坏惰性清理
- 外部设备绑定默认只提供管理/远程 GUI；自动执行需 `DeviceExecutor`

---

## E. 产线图纸生命周期

### E1. 框选与捕获

- 类结构方块的角点/尺寸模式
- 体积上限与危险方块黑名单
- 捕获方块态、BE NBT、初始容器/流体/能量
- 捕获天穹节点配置（若存在）
- 生成未测试图纸（物品引用 + 服务器库存储）

### E2. 沙盒测试

- 粘贴到测试维隔离槽
- 屏障包围
- 玩家观察者模式进入查看
- 手动停止 / 超时 / 稳态窗口结束
- 退出后还原玩家状态，禁止带出测试产物

### E3. 计量与报告

- 内容器/流体/能量差分
- 天穹跨界进出计量（核心）
- 报告：耗材 CAPEX、运行输入、运行输出、净能量、周期估计、警告
- 玩家确认后编译

### E4. 编译产物

- `blueprint_compiled` 锁定：
  - 结构哈希
  - 耗材清单（方块 + 初始库存）
  - 材料消耗
  - 材料产出
  - 周期 tick
  - 版本号

### E5. 量产与复制

- 驱动器：扣输入 → 等待周期 → 吐输出
- 模式：定时 / 红石门控 / 创意瞬发
- 并行度升级
- 复制台：按 CAPEX 从 BD 网络扣料复制图纸

## F. 天穹物流联动功能

- 测试维节点默认允许与原维同线路跨维传输
- 跨界传输记为产线外部 IO
- 无天穹物流时降级：仅内部容器差分，功能不崩溃
- 报告标注物流桥接状态

---

## G. 超越维度联动功能

- 从 BD GUI 解析当前网络
- 使用 `UnifiedStorage` 做材料源/汇
- 复用/对接网络熔炉等自有设备
- 权限与成员校验
- JEI/EMI 搜索同步策略与 BD 配置共存

---

## H. 运行时横切功能

- 材料账本（预留、提交、退款）
- 图调度器（依赖、并行、负载均衡）

- 进度 HUD
- 诊断命令与审计日志开关
- 服务器预算（每 tick 粘贴方块数、规划超时、并行链上限）
