# 01 · 产品愿景与边界

## 1. 愿景

Beyond: Craftlines 让超越维度网络具备两条互补能力：

1. **合成链（Craft）**：像共振存储那样，在 JEI/BD 界面预览工作树并一键递归完成配方。
2. **产线链（Lines）**：把真实世界中的一段产线框成图纸，经沙盒测试验证 IO 后，编译为可调用、可复制、可自动执行的黑盒产线配方。

两者共享同一套材料账本、网络权限与资源键模型，从而在“单配方自动做”和“整厂封装复用”之间无缝衔接。

## 2. 设计原则

1. **BD 原生优先**：默认可执行范围收敛到超越维度自有设备与原版合成，避免一开始陷入无限模组兼容泥潭。
2. **真实产线可验证**：编译图纸必须以沙盒计量结果为依据，而不是手填 IO。
3. **物流边界清晰**：产线外部输入输出优先用天穹跨界流量定义，而不是只看内部箱子差分。
4. **可降级**：没有 JEI/天穹/Jade 时核心不崩溃，只减少入口或计量精度。
5. **多版本同构**：`common + versions/{1.20.1,1.21.1,26.1.2}`，行为语义三版本一致，平台差异关在版本适配层。

## 3. 目标用户旅程

### 3.1 合成链用户

1. 打开 BD 维度网络界面。
2. 在 JEI 中出现 Craftlines `预览/下单` 按钮；或对网络物品中键进入下单界面。
3. 查看 EMI 风格配方树、缺料与步骤，选择重复次数与产物去向。
4. 下单执行；熔炉/合成自动推进；查看进度 HUD。
5. 产物进入 BD 网络；可由稳态构象图产出的物品显示特殊标记。

### 3.2 产线链用户

1. 在主世界搭好产线，并用天穹节点对外收发。
2. 放置框选锚点，保存未稳构象图。
3. 启动测试，观察者模式进入沙盒维查看；离开产线范围 5 秒自动退出观察。
4. 系统统计跨界 IO 与内部存量变化，生成报告。
5. 确认报告，得到稳态构象图。
6. 将图纸放入驱动器自动跑，或在 JEI 缺料时作为获取来源；需要时用复制台按耗材复制。

## 4. 与参考模组关系（不改本设计）

| 参考 | 可借鉴点 | 本模组差异 |
| --- | --- | --- |
| RS Integration（共振存储） | JEI 工作树、绑定、账本、进度 | 网络底座是 BD，不是 RS；默认可执行族更收敛 |
| ModuleWorks（ggg_moduleworks） | “把工厂压进可试产单元/压缩空间试产”的产品直觉 | 本模组用**测试维沙盒 + 编译图纸 + BD/天穹计量**，不是简单缩厂方块 |
| Sky Logistics | 跨维线路、节点升级、多版本仓结构 | 本模组消费其跨界能力，并定义沙盒特例 |
| Beyond Dimensions | UnifiedStorage、网络熔炉、终端 JEI 转移 | 本模组补齐递归规划与产线封装 |

## 5. 成功标准（最终态）

1. 仅 BD + JEI 时，可完成原生配方工作树预览与执行。
2. BD + 天穹物流时，可完成框选-测试-编译-驱动闭环，报告跨界 IO 与观察一致。
3. 稳态构象图可被工作树嵌套调用，且循环依赖被拒绝。
4. 三版本行为一致，平台差异不泄漏到玩法语义。
5. 无软依赖时功能降级，不硬崩溃。
