# 13 · 测试策略与 UT 清单

## 1. 测试金字塔

1. **common 单元测试**：规划、账本、状态机、计量推导（占比最高）
2. **版本集成测试**：注册、网络包、软依赖降级
3. **游戏内验收脚本/手测清单**：三版本各跑一遍关键路径

## 3. 版本集成测试

每版本至少：

- [ ] 模组加载
- [ ] 物品/方块注册名齐全
- [ ] 菜单打开不崩
- [ ] 缺 JEI/天穹时启动成功
- [ ] mixin 应用成功（若有）

## 4. 游戏内验收清单（最终态）

1. BD 终端打开 JEI，对合成物品预览工作树并执行成功。
2. 绑定网络熔炉，完成烧炼前置。
3. 框选含天穹节点的小型产线，测试维生成屏障。
4. 原维向测试维送料，报告出现对应输入；产物跨回原维计入输出。
5. 确认编译，驱动器自动跑至少 3 个周期。
6. 复制台扣 CAPEX 复制图纸。
7. JEI 对图纸产出物显示黑盒来源并可嵌套执行。
8. `/beyond_craftlines cancel` 可取消合成链并退料。

## 5. 性能基线（建议记录）

- 规划 1k 节点 < soft timeout
- 32³ 粘贴在可接受 tick 数内完成
- 驱动器 20 并行不拖垮 TPS（在测试档位下）
