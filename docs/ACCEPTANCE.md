# Beyond: Craftlines 验收文档

本文用于验收合成链供给器的配方类型确认 GUI。案例使用 Create 工作盆，因为同一个
`create:basin` 催化剂通常会被 JEI 同时登记到以下配方类型：

- `create:mixing`：搅拌；
- `create:compacting`：压块。

界面显示文本会随 Create/JEI 语言包变化，验收时以 JEI 当前登记结果为准；在本文指定的
Create 6.0.9 环境中，预期至少出现“搅拌”和“压块”两项。

## 1. 验收环境

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.194 或更高版本 |
| Beyond Dimensions | 0.7.27 |
| Beyond: Craftlines | 当前待验收构建 |
| JEI | 19.44.0.401 |
| Create | 6.0.9 |

建议新建测试世界并开启作弊。验收玩家需要先连接一个 Beyond Dimensions 网络，并拥有该网络的管理员权限。

准备以下物品：

- 合成链供给器；
- 网络联结器；
- Create 工作盆；
- Jade（用于检查最终启用类型，可选但推荐）。

## 2. 基础布置

1. 确认当前玩家已连接到一个自己可管理的 Beyond Dimensions 网络。
2. 放置合成链供给器，确认它已绑定到当前网络。
3. 在附近放置一个 Create 工作盆。
4. 确认 JEI 中工作盆被登记为搅拌和压块配方的催化剂。

预期结果：供给器和工作盆均保持加载，供给器可正常识别当前网络；此时尚未扫描工作盆。

## 3. GUI 默认可打开，未扫描时没有选项

1. 不使用网络联结器，普通右击合成链供给器。
2. 观察供给器 GUI。

预期结果：

- GUI 正常打开，不要求先完成工具绑定；
- 列表中没有任何可勾选的配方类型；
- 界面显示“请先用网络联结器绑定并扫描目标方块”；
- 界面没有文本输入框，也没有添加任意配方 ID 的入口。

## 4. 使用工作盆生成候选选项

1. 关闭供给器 GUI。
2. 手持网络联结器，潜行右击合成链供给器。
3. 确认出现“已选择此合成链供给器”的提示。
4. 使用同一个网络联结器普通右击 Create 工作盆。
5. 确认出现“已将识别到的配方类型加入供给器候选项”的提示。
6. 普通右击供给器，重新打开 GUI。

预期结果：

- GUI 中出现工作盆经 JEI 识别得到的候选类型；
- Create 6.0.9 标准环境中至少包含“搅拌”和“压块”，对应 UID 分别为
  `create:mixing` 和 `create:compacting`；
- 新出现的候选项默认未启用，扫描动作本身不会自动让供给器承接这些配方；
- 除已扫描候选外，不能创建或填写其他类型。

如果没有出现选项，先在 JEI 中确认工作盆确实是对应 category 的正式催化剂，再检查 JEI
运行时索引是否已经初始化；这不应通过手工输入 UID 绕过。

## 5. 手动确认单个配方类型

1. 在供给器 GUI 中只勾选“搅拌”。
2. 保持“压块”未勾选。
3. 点击“保存”。
4. 再次打开供给器 GUI。
5. 使用 Jade 查看供给器提示。

预期结果：

- 再次打开 GUI 后，“搅拌”保持勾选，“压块”保持未勾选；
- Jade 只显示已启用的“搅拌”，不显示仅作为候选存在的“压块”；
- Craftlines 将该供给器视为 `create:mixing` 的可用供给端点；
- Craftlines 不会将该供给器视为 `create:compacting` 的可用供给端点。

## 6. 手动确认多个配方类型

1. 再次打开供给器 GUI。
2. 同时勾选“搅拌”和“压块”。
3. 点击“保存”，然后重新打开 GUI。
4. 使用 Jade 查看供给器提示。

预期结果：

- 两个选项均保持勾选；
- Jade 同时显示“搅拌”和“压块”；
- 供给器可同时作为 `create:mixing` 和 `create:compacting` 的供给端点。

## 7. 取消已启用类型

1. 在 GUI 中取消勾选“搅拌”，只保留“压块”，然后保存。
2. 重新打开 GUI，并使用 Jade 检查。
3. 再取消所有勾选并保存。

预期结果：

- 第一次保存后只有“压块”生效，“搅拌”仍保留为可再次勾选的候选项；
- 全部取消并保存后，供给器不再承接任何配方类型；
- 已扫描候选仍显示在 GUI 中，玩家可再次勾选，不需要重复扫描。

## 8. 禁止手工填写与服务端校验

执行以下检查：

1. 在 GUI 中按字母键、数字键并尝试粘贴 `create:pressing`。
2. 检查界面是否存在新增、自定义或文本编辑入口。
3. 如使用测试客户端构造配置数据，尝试提交未扫描的 `create:pressing`。

预期结果：

- 正常 GUI 不响应配方 UID 文本输入；
- 玩家只能切换服务器下发的已扫描候选项；
- 服务端拒绝候选集之外的类型，并提示只能选择网络联结器扫描得到的类型；
- 原配置不会因非法提交而改变。

## 9. 权限校验

1. 使用没有该 BD 网络管理权限的另一名玩家普通右击供给器。
2. 确认 GUI 仍可以打开并查看当前配置。
3. 修改勾选状态并点击“保存”。

预期结果：

- GUI 的默认打开行为不受影响；
- 服务端拒绝无管理权限玩家的保存请求；
- 原有启用类型保持不变。

## 10. 持久化与旧配置兼容

1. 勾选“搅拌”和“压块”并保存。
2. 退出并重新进入世界，或重启服务端。
3. 重新打开供给器 GUI，并使用 Jade 检查。

预期结果：

- 工作盆扫描得到的候选项仍然存在；
- 保存的勾选状态保持不变；
- Jade 与订单可用配方族保持一致；
- 从旧版本升级时，旧存档中已启用的供给器类型会自动加入候选集，不会因缺少新字段而消失。

## 11. 清空与库存回归

1. 手持网络联结器，潜行右击供给器以重新选择它。
2. 对空气使用网络联结器。
3. 打开供给器 GUI。
4. 如果供给器内已有订单资源，点击“取出一组”。

预期结果：

- 对空气使用联结器后，候选和已启用类型全部清空；
- GUI 仍可正常打开，但恢复为无选项状态；
- Jade 显示供给器未绑定配方；
- “取出一组”仍能将一种资源的一组物品放入玩家背包，背包已满时掉落到玩家附近；
- 外部管道仍可提取，但玩家和管道仍不能向供给器写入资源。

## 12. 验收结论

以下条件全部满足时，本功能通过验收：

- 供给器 GUI 无需预先扫描即可打开；
- 未扫描时没有可选择项；
- Create 工作盆扫描后能展示 JEI 返回的多种配方类型；
- 扫描不会自动启用类型，必须由玩家勾选并保存；
- 可以独立启用、取消或同时启用“搅拌”和“压块”；
- GUI 无手工填写入口，服务端拒绝候选集外的提交；
- 权限、持久化、Jade 展示和库存提取行为符合上述预期。
