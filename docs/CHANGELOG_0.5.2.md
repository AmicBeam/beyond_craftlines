# 0.5.2

改进 JEI 配方关联、多产物规划和大网格输入识别，修复资源重载后的缓存复用，并适配新版 BD 网络侧边栏。

同时适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge。

三个版本均需安装对应 Minecraft 版本的 **Beyond Dimensions 0.7.30 或更高版本**及 JEI。

### 主要更新

- 保留 JEI 显式关联槽位，避免输入输出候选错配；未知资源、无法证明的输出关联或超限描述不再被静默缩减。
- 支持完整采集最多 256 个输入槽（包括 81 格配方），每槽 256 候选、总计 8192 候选。大网格自动工作台代理不在本次范围内。
- 多产物随上传、规划、目录缓存和订单存档保存；确定副产物抵扣后续需求，补充依赖，实际产物安全回收和返还。
- 增加输出概率与说明图标策略。内置 Create 概率规则与 Occultism 仪式说明图标过滤，概率结果不再作为保证交付目标。
- 新增 Botania 花药台/符文祭坛、Embers 炼金、Occultism 仪式、Theurgy 孵化、Industrial Foregoing 溶解室六个输入分组 profile；Goety 支持动态 ritual_ 分类前缀。
- 输入分组仍由 assets 与资源包维护；支持固定槽计数和配方父类选择，不新增玩家配置页面。
- 修复配方、tag/profile 等资源变化但 ID 不变时的缓存复用风险。缓存格式 v3 按资源会话隔离，保留同会话复用，不再跨登录复用仅凭 ID 验证的缓存。
- 升级网络协议到 26，补齐 26.1.2 的 JEI Mixin 接线；该版本继续不启用 EMI。
- 合成状态与仪表盘状态入口改由 BD 左侧栏统一排列，移除固定坐标定位；在网络界面初始化末尾添加按钮，使 BD 调整显示行数、窗口大小或 GUI 缩放后重建界面时仍能恢复入口。
- 三个版本的 BD 最低依赖统一升级到 0.7.30；1.20.1 同时适配开发环境和 Forge 发布环境的初始化方法名。构建默认从 Modrinth 获取对应版本的 BD。

兼容验收聚焦确定性配方识别，产线条件与动作由玩家负责；随机配方不列为本轮目标。此责任边界澄清不改变已有概率过滤、订单投料或回收实现。
