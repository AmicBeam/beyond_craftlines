供给器新增均分模式，每批原料可按供应目标容量自动均分。

### 主要更新

- 投送按钮新增“均分”，保留轮询、最近优先和最远优先。
- 每种资源独立批量均分，余数始终按绑定顺序优先给前面的可用目标，不保存余数起点。
- 容量不足的份额继续均分给其他可接收目标，无法发送的资源留在供给器。
- 补充中英文界面、使用说明和均分测试，保留原有投送模式的存档编号。

### 支持版本

- Minecraft 1.20.1 / Forge
- Minecraft 1.21.1 / NeoForge
- Minecraft 26.1.2 / NeoForge

本 Release 按发布要求不附带 JAR 或其他构建附件。
