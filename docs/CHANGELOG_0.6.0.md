# 0.6.0

新增跨登录配方缓存与增量恢复，修复大型整合包反复索引、星祭坛配方缺失／重复和配方树悬浮显示问题。

本页整理自 `0.5.3` tag 到当前版本的净变化，同时适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge。

## 配方缓存与加载

- JEI 执行描述和规划目录均可跨退出世界、游戏重启复用，并按 Minecraft 版本、单人存档或多人服务器隔离。
- `[planning] preloadAllRecipeTypes = true` 默认开启，首次进入世界预热全部受支持配方类型；设为 `false` 可按网络启用类型预热。绑定机器和勾选类型只改变网络可执行范围。
- 配方 ID 增删时复用未变记录，只捕获新增／缓存无记录的配方并移除已删除项。JEI 分类来源变化时只更新相关分类。
- 移除配方缓存的额外规模上限，避免大型目录因超过配方数、条目数或文件大小限制而跳过保存；继续使用流式压缩、后台读写和原子替换。
- 使用规范化资源数据生成稳定的虚拟配方 ID，自动迁移旧描述缓存、规划记录、默认配方和原料选择；迁移后合并等价旧 ID，避免重复候选。
- 单条描述校验／资源解码失败只重载所属分类，保留其他有效分类。布局创建中的单条配方异常不会截断整个分类；文件结构或 GZIP 校验损坏时明确记录并重新加载。
- 缓存完整命中时在后台准备查询索引，检查世界／运行时 generation 后安装，避免旧任务向新世界发布结果。

## 兼容与界面修复

- 适配 JEI 19.57+ 的 Optional 布局返回值，修复布局关联丢失导致的配方识别问题。
- 增加 Modern Industrialization 星祭坛的显式原生配方回退，支持概率均为 1、单一物品产出且没有流体输入输出的配方；修复 EMI 抑制对应 JEI 分类时配方树无法展开，以及纯 JEI 下出现重复候选的问题。
- 修复烧炼、高炉和烟熏配方候选缺失，改进循环分支回退与 EMI 规划稳定性。
- JEI／EMI 下单入口记住最近可访问的网络；Forge 菜单读取当前打开网络的库存，修复共享／切换网络时使用错误上下文的问题。
- 工作站输入解析共享缓存，减少重复枚举物品注册表；非工作台配方跳过无关的工作台基线样本构造。
- 缺料提示和物品 tooltip 在前景显示；配方树范围外不再响应被裁剪节点的悬浮提示。
- 来源校验、JEI 缓存读取、规划缓存读取、补充索引和查询索引分别显示。补充索引的数字与进度条使用同一组待补配方计数，切换阶段时同步更新。
- 修复绑定高亮在着色器批处理下的刷新与显示问题。

## 升级与排查

- 网络协议升级到 **27**，多人服务器与客户端需要同时更新。三个版本均需对应 Minecraft 版本的 Beyond Dimensions 0.7.30 或更高版本及 JEI；EMI 联动适用于 1.20.1、1.21.1，26.1.2 保持 no-op。
- 客户端命令 `/craftlines reload` 无需 OP，可清除当前存档／服务器的两份配方缓存并重新加载。修改配方、KubeJS、标签或 IO profile 后，如果 ID 没变，应执行该命令；没有权威原生 ID、类和数量也未变的展示配方同样适用。
- 原缓存可保留并迁移。缓存命中仍包含来源校验、读盘解压、资源还原和查询索引准备。
- `client planning catalog ready` 表示内存目录就绪；`client planning cache saved` 和 `client JEI cache save result=INSTALLED` 才表示各自的磁盘文件已保存。
- 日志提供缓存命中／失效原因、分类与 ID 迁移数量、增量复用／补捕获／删除数量，以及来源校验、读缓存和创建布局的阶段进度。搜索 `slow recipe index` 可查看达到 20ms 的慢操作；明细有界并保留汇总。

## 支持版本与验证

- Minecraft 1.20.1 / Forge / Java 17
- Minecraft 1.21.1 / NeoForge / Java 21
- Minecraft 26.1.2 / NeoForge / Java 25

三个版本均完成构建和自动回归；覆盖旧缓存及偏好迁移、资源 ID 稳定性、分类失败隔离、增量合并、重复 ID 去重、坏布局继续处理和旧世界任务隔离。ATM10 的实际重进耗时仍需游戏内复测，自动回归不替代整合包实机验收。
