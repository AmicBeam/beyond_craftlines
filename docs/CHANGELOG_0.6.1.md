# 0.6.1

修复第三方展示配方触发 JEI 扩展异常时打开配方页面闪退的问题，并补充配方缓存重载说明。

本次以上一份正式发布 `0.6.0`（提交 `e4ef28f`）为基线，整理至本版本的净变化。适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge。

### 主要更新

- 为 JEI 下单按钮创建、虚拟配方读取和按目标搜索增加单条配方异常隔离，避免 Create: Trading Floor 等模组的展示配方在 `getType()` 等接口中抛出异常时导致 Craftlines 扩展入口崩溃。
- 仅跳过抛异常配方的 Craftlines 按钮或索引项，保留 JEI 原有页面；同分类的其他正常配方继续按原规则处理。
- 诊断日志记录处理阶段、JEI 分类、配方实现类和异常；同类诊断去重，每轮最多 128 条。诊断本身读取失败也会隔离。
- 补充中英文 README、游戏内指南及独立缓存文档，说明 `/craftlines reload` 的权限、作用范围、数据重载顺序及保存完成标志。

### 升级说明与验证

- 网络协议保持 **27**；三个版本仍需对应 Minecraft 版本的 Beyond Dimensions 0.7.30+ 和 JEI。EMI 联动适用于 1.20.1、1.21.1，26.1.2 保持 no-op。
- 异常配方暂时不提供 Craftlines 下单入口；正常配方的按钮判定规则保持原有行为。
- 三个版本均执行发布构建和自动回归；新增测试覆盖异常配方前后的正常按钮、索引结果、第三方 API 链接异常、诊断失败隔离及致命错误传播。
- Create: Trading Floor 整合包中的实际游戏验收仍待复测，自动回归不替代实机验证。

### 支持版本

- Minecraft 1.20.1 / Forge / Java 17
- Minecraft 1.21.1 / NeoForge / Java 21
- Minecraft 26.1.2 / NeoForge / Java 25
