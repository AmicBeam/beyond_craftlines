# Beyond: Craftlines 0.7.0

新增可给出具体操作步骤的智能排查，改进库存可行搜索、组件候选与动态产物处理，并提供五个 Minecraft 版本及两个 BD 0.8 专用构建。

本次以上一份正式发布 `0.6.1`（提交 `df2668f`）为基线，整理至本版本的净变化。适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.2 NeoForge 和 26.3 NeoForge，五个版本及 BD 0.8 专用构建统一为 `0.7.0`。本次为同版本重发，替换此前的 `0.7.0` tag 和 Release；完整变化仍以上一正式版本 `0.6.1` 为基线。

### 主要更新

- **智能排查与明确方案**：合成树新增 root 不符、缺少分类、NBT/组件、无法下单和制作卡住五类入口。期望 JEI 分类支持按名称、ID 和原版炉类别名搜索的下拉框。分类排查会向服务端核对当前网络，区分没有绑定记录、已有记录但不可用、已经启用，再从 JEI/EMI 工作站元数据中找出具体设备，给出连接器或供给器的逐步配置方案；有序步骤分别换行。
- **订单执行排查**：在合成状态中选中订单，可查看随状态更新的建议、配方 ID、类型、已记录承接端位置和回收数量。覆盖材料组未分配、空间不足、过滤拦截、阻挡模式、前置步骤、等待产物及最终交付问题；提交拒绝会回传稳定错误码，区分冷却、订单上限、库存变化等原因。未知原因保持待核实，不把“加工中”当成已验证机器在运行，也不会自动改绑定或库存。
- **手动树独立验证预算**：候选搜索耗尽预算后，当前已选树仍使用独立的新预算验证；手动配方和原料选择保持优先。后台更优方案搜索失败不覆盖已有可制作方案。验证仍受自身时间、节点和深度限制，缺料或无效选择仍不能下单。
- **组件候选与真实动态产物**：精确匹配失败时可显式选择同资源的 NBT/组件变体候选，并显示差异提示；近似排序不改变全局库存相等判断。工作台等真实执行产生的动态组件按订单记录、保存并传递给后续步骤和交付，不再默认发布 `slashblade.json`。自动补货遇到与目标不同的实际组件时暂停提示，避免重复生产无法计入目标的变体。
- **按飞行时间区分普通火箭**：普通推进火箭按三个飞行时间展开对应方案，保留火药独立槽位，按真实配方结果校验组件与产量，避免用低飞行时间火箭代替目标。本轮不覆盖带烟火之星、爆炸效果或额外自定义状态的火箭。
- **BD 兼容分包**：五个 Minecraft 版本的常规包明确标记 `for-bd0.7` 并限制 BD `<0.8`；Minecraft 1.20.1 和 1.21.1 另提供 `for-bd0.8` 专用构建，适配新版页面入口、同步与存储接口，要求 BD `[0.8.8,0.9)`、CompixelUI 和 Kotlin。同一实例只安装一个匹配的 Craftlines 包。
- **更清晰的配方预览与项目入口**：有序合成的悬停预览保留原始格子布局；JAR 模组元数据增加 GitHub 项目主页，方便从模组信息中访问仓库。
- **偏好优先的库存可行搜索**：优先尝试玩家保存的配方，无法完成完整订单时回退其他配方或选材；找到第一个完整可制造方案后停止搜索。同一种资源在一份计划中仍只选择一个生产配方，本次手动固定的选择保持有效。服务端继续以最新库存复核，缺料时拒绝创建订单。
- **仅使用库存的配方选择**：配方候选新增禁止制造选项，可指定某项资源仅使用现有库存；缺料时不继续展开其原料。选择可保存为偏好，也可通过“忘记偏好”恢复自动选择。循环分支默认停止展开，并可通过客户端设置显示循环标记。
- **更紧凑的配方树与候选信息**：新增 35% 和 25% 紧凑预览；配方候选标题优先显示首项原料，悬停可查看完整信息。
- **订单列表分页**：优先展示未完成订单，支持分页浏览记录，避免较多订单被固定返回上限截断。
- **供给器与机器过滤配置**：右上角新增过滤入口，保留原面板尺寸，提供 36 格标记列表和真实玩家物品栏。支持黑／白名单、忽略／匹配 NBT，以及互斥的匹配原料／匹配产物。匹配对象用于筛选承接的配方与订单；产物模式检查本次配方的目标产物，原料无需同时命中产物白名单，产物与副产物回收不再被同一列表再次拦截。耐久值始终忽略。
- **统一标记操作与设置反馈**：拿取物品后点击指定格设置标记，Shift 点击快捷添加，空鼠标点击清除；支持 JEI 拖入标记。过滤设置按钮排列在列表下方，选中时整体变色，并保存列表及选项。1.20.1 与 1.21.1 还支持 EMI 拖入与中键标记。
- **仪表盘容器资源标记**：持有桶／储罐右键样品格可标记其中的流体或已注册的化学品资源；左键标记容器物品，空鼠标右键清空。标记不消耗或排空真实容器。
- **新增版本适配**：新增 Minecraft 26.2 和 26.3 NeoForge 构建，搜索、订单、配置和资源功能覆盖五个支持版本。

### 升级说明与验证

- 网络协议升级为 **34**；客户端和服务端需使用同一版本。规划缓存格式升级至 6，旧格式缓存会自动失效并重建；自行修改配方、标签或 I/O profile 后可用 `/craftlines reload` 刷新。
- 1.20.1、1.21.1 与 26.1.2 需要对应版本的 Beyond Dimensions **0.7.30+**；26.2 与 26.3 需要 **0.7.31+**。常规包的 BD 上限均为 `<0.8`；BD 0.8 专用包要求 `[0.8.8,0.9)`。五个版本均需 JEI；EMI 为 1.20.1、1.21.1 的可选联动，三个 26.x 版本目前不提供 EMI 运行支持。
- NBT 选项作用于物品；NeoForge 比较组件，Forge 比较 NBT，均忽略耐久。流体与化学品沿用完整资源键匹配。旧开发版过滤配置默认迁移为原料模式，保留列表与 NBT 选项，旧耐久开关不再生效。
- Minecraft 26.3 使用 NeoForge 同步配置：全局配置位于 `config/beyond_craftlines-server.toml`，世界覆盖位于 `syncedconfig/beyond_craftlines-server.toml`。从旧开发构建升级时，可将原世界 `serverconfig` 中需要保留的配置复制到 `syncedconfig`。
- 七套构建均执行发布用 `clean build` 和自动回归，覆盖搜索回退、手动选择独立验证、组件身份与动态产物、分类绑定查询、订单诊断、分页和过滤等行为。自动测试不替代游戏内验收；界面与整合包的实际游戏验证尚未完成。26.3 对应的 NeoForge 仍为 beta。

### 支持版本

| Minecraft | Loader | JDK | BD 0.7 常规包 | BD 0.8 专用包 |
| --- | --- | --- | --- | --- |
| 1.20.1 | Forge 47 | 17 | 支持 | 支持，Forge 至少 47.2.18 |
| 1.21.1 | NeoForge 21.1 | 21 | 支持 | 支持 |
| 26.1.2 | NeoForge 26.1.2 | 25 | 支持 | 暂无 |
| 26.2 | NeoForge 26.2 | 25 | 支持 | 暂无 |
| 26.3 | NeoForge 26.3 beta | 25 | 支持 | 暂无 |

常规构建产物为各目标 `build/libs` 下的 `beyond_craftlines-0.7.0+<Minecraft 版本>-for-bd0.7.jar`；两个 BD 0.8 专用构建位于 `versions/1.20.1-bd0.8/build/libs` 和 `versions/1.21.1-bd0.8/build/libs`，文件名以 `-for-bd0.8.jar` 结尾。构建产物保留在本地，本 Release 按发布要求不附带 JAR 或其他构建附件。
