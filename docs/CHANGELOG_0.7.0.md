# Beyond: Craftlines 0.7.0

改进库存可行配方搜索与订单浏览，新增供给器／机器过滤配置和容器资源标记，并将支持范围扩展到五个 Minecraft 版本。

本次以上一份正式发布 `0.6.1`（提交 `df2668f`）为基线，整理至本版本的净变化。适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.2 NeoForge 和 26.3 NeoForge，五个版本统一为 `0.7.0`。

### 主要更新

- **偏好优先的库存可行搜索**：优先尝试玩家保存的配方，无法完成完整订单时回退其他配方或选材；找到第一个完整可制造方案后停止搜索。同一种资源在一份计划中仍只选择一个生产配方，本次手动固定的选择保持有效。服务端继续以最新库存复核，缺料时拒绝创建订单。
- **仅使用库存的配方选择**：配方候选新增禁止制造选项，可指定某项资源仅使用现有库存；缺料时不继续展开其原料。选择可保存为偏好，也可通过“忘记偏好”恢复自动选择。循环分支默认停止展开，并可通过客户端设置显示循环标记。
- **更紧凑的配方树与候选信息**：新增 35% 和 25% 紧凑预览；配方候选标题优先显示首项原料，悬停可查看完整信息。
- **订单列表分页**：优先展示未完成订单，支持分页浏览记录，避免较多订单被固定返回上限截断。
- **供给器与机器过滤配置**：右上角新增过滤入口，保留原面板尺寸，提供 36 格标记列表和真实玩家物品栏。支持黑／白名单、忽略／匹配 NBT，以及互斥的匹配原料／匹配产物。匹配对象用于筛选承接的配方与订单；产物模式检查本次配方的目标产物，原料无需同时命中产物白名单，产物与副产物回收不再被同一列表再次拦截。耐久值始终忽略。
- **统一标记操作与设置反馈**：拿取物品后点击指定格设置标记，Shift 点击快捷添加，空鼠标点击清除；支持 JEI 拖入标记。过滤设置按钮排列在列表下方，选中时整体变色，并保存列表及选项。1.20.1 与 1.21.1 还支持 EMI 拖入与中键标记。
- **仪表盘容器资源标记**：持有桶／储罐右键样品格可标记其中的流体或已注册的化学品资源；左键标记容器物品，空鼠标右键清空。标记不消耗或排空真实容器。
- **新增版本适配**：新增 Minecraft 26.2 和 26.3 NeoForge 构建，搜索、订单、配置和资源功能覆盖五个支持版本。

### 升级说明与验证

- 网络协议升级为 **31**；客户端和服务端需使用同一版本。
- 1.20.1、1.21.1 与 26.1.2 需要对应版本的 Beyond Dimensions **0.7.30+**；26.2 与 26.3 需要 **0.7.31+**。五个版本均需 JEI；EMI 为 1.20.1、1.21.1 的可选联动，三个 26.x 版本目前不提供 EMI 运行支持。
- NBT 选项作用于物品；NeoForge 比较组件，Forge 比较 NBT，均忽略耐久。流体与化学品沿用完整资源键匹配。旧开发版过滤配置默认迁移为原料模式，保留列表与 NBT 选项，旧耐久开关不再生效。
- Minecraft 26.3 使用 NeoForge 同步配置：全局配置位于 `config/beyond_craftlines-server.toml`，世界覆盖位于 `syncedconfig/beyond_craftlines-server.toml`。从旧开发构建升级时，可将原世界 `serverconfig` 中需要保留的配置复制到 `syncedconfig`。
- 五个版本均完成完整构建和自动回归，覆盖搜索回退、仅库存选择、订单分页、过滤接单、选项保存／迁移等行为。自动测试不替代游戏内验收；界面与整合包的实际游戏验证尚未完成。26.3 对应的 NeoForge 仍为 beta。
