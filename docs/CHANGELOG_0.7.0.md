# Beyond: Craftlines 0.7.0

适用于 Minecraft 1.20.1 / Forge、1.21.1 / NeoForge、26.1.2 / NeoForge、26.2 / NeoForge 和 26.3 / NeoForge，五个版本统一为 `0.7.0`。

## 偏好优先的库存可行搜索

- 最优搜索的目标改为找到一个能由当前网络库存完成的完整订单方案；优先尝试玩家保存的配方，无法完成时回退其他路线。
- 保存的偏好作为优先尝试的建议；本次在树中明确指定的配方和原料仍按固定选择校验。
- 找到第一个完整可制造方案后停止搜索，不枚举所有可行解，不要求证明全局最短。较短生产链只作为次要的搜索顺序参考。
- 同一种资源在一份计划中仍只选择一个生产配方，保留完整组件身份、机器类型限制、工具耐久、复用输入、自增种子和保证副产物语义。
- 后续材料分支缺料时，可以回退此前的配方或选材，并恢复该分支的模拟库存和选择，避免局部可制造的配方抢占另一分支必需的材料。
- 每次尝试从原始库存重新模拟，选择记录保存在堆上；递归深度只跟随配方依赖深度，宽分支图不会累积兄弟分支的 Java 调用栈。已经缺料后的无关分支不再创建新的回退选择。
- 候选排序读取包含本单保证副产物的当前模拟库存；保留全部匹配保存偏好的候选。快速预览沿用基准、单槽替换和等价槽统一替换；开启完整搜索后可以组合多个槽位的替换。
- 服务端继续按最新库存沿客户端固定选择复算；库存变化或缺料时拒绝创建订单。

## 版本与交付

五个 Minecraft 版本使用同一搜索目标，分别以 Java 17、21、25、25、25 构建。产物为各自 `build/libs` 下的 `beyond_craftlines-0.7.0+<Minecraft 版本>.jar`。

“无配方”选择与循环节点显示设置作为独立提交保留，同样属于 `0.7.0`，详见 [无配方选择说明](NO_RECIPE_SELECTION.md)。
