# Beyond: Craftlines 0.7.1

本版本未单独发布 GitHub Release，以下更新已合并到 [0.7.2 发布说明](CHANGELOG_0.7.2.md)。

修复同物品 ID、不同 NBT/组件的配方固定与偏好互相影响的问题，并改进候选列表和排查入口。

本次以上一份正式发布 `0.7.0`（提交 `0bc5381`）为基线。覆盖 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2、26.2、26.3 NeoForge，以及 1.20.1、1.21.1 的 BD 0.8 专用构建。

### 主要更新

- 配方入口固定、手动固定、保存/加载偏好、自动方案及服务端固定链均按完整资源键区分 NBT/组件，不再把选择投影到物品 ID，也不再从精确键回退到物品 ID 级记录。抗火药水的配方固定不会接管粗制药水、水瓶等前置节点。
- 保留偏好路线不可行时搜索同一精确目标其他配方的行为；显式固定和“仅使用库存”仍对各自精确目标生效。
- 忽略旧的纯物品 ID／粗键偏好，但不删除配置文件中的这些记录。请在具体物品样本上重新选择偏好；已有精确键记录继续可用。旧仪表盘若保存的是粗键固定链，需要按精确目标重新配置。
- 配方候选含近似条目时，在“遗忘偏好”左侧显示“隐藏近似”按钮，点击后切换为“显示近似”。没有已保存偏好时按钮靠右显示。切换只影响本次候选列表，不改变选择、偏好或规划；显示选择与“存入物品栏／网络”一起保存在同一份客户端偏好文件，后续打开沿用；旧配置默认显示全部。无法确认产物身份的条目不会被当成近似项隐藏。
- 候选标题与操作按钮分行显示，避免中英文按钮挤占标题；切换显示范围后返回第一页。
- 合成状态页智能排查按钮改为标题行最右侧的 `!`，网络编号相应左移。“无法下单”只分析当前规划/缺料，不显示“查看订单排查”；该跳转仅用于“制作卡住”。

### 升级说明

- 模组版本统一为 `0.7.1`，网络协议升级至 **35**；客户端和服务端必须配套更新。
- BD 0.7 常规构建仍要求 BD `<0.8`；1.20.1、1.21.1 的 BD 0.8 专用构建要求 BD `[0.8.8,0.9)`。同一实例只安装一个对应构建。
- 流体、化学品及普通精确库存匹配保持原有身份规则；近似候选仍须显式选择，不能使其他组件的库存变成相等。
- 游戏内药水生产链、窗口布局及真实第三方设备流程尚需实机验收；自动回归不替代游戏内验证。
