# 0.7.2

适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.2 NeoForge、26.3 NeoForge 的 BD 0.7 构建，以及 1.20.1、1.21.1 的 BD 0.8 构建。

- 容器模式的仪表盘只需设置目标资源和维持数量，即可从 BD 网络搬运现有库存，无需配置配方树。网络缺货时等待后续检查，来货后继续补充。
- 配置了配方树时，继续先搬运网络库存，仅对剩余缺口自动合成；网络库存模式仍需配置配方。
- 自动订单数量上限仅限制创建合成订单，不再阻挡直接搬运。已有自动订单仍按原流程执行和交付，避免重复补货。
- 无配方的容器仪表盘纳入网络仪表盘状态列表，配置页不再显示配方未配置错误，设置配方树按钮标为可选。
- 保持原有精确资源匹配、红石控制、容器空间限制与未插入资源退回网络的行为。

使用方法：将仪表盘贴在目标容器上，标记资源，切换到容器库存模式并设置维持数量。配方树可留空；纯搬运不创建合成订单。

验证：七个构建均完成 `build` 并通过全部单元测试；已检查 JAR 中的 0.7.2 元数据、对应 Java 17 / 21 / 25 字节码和新增界面文案。1.20.1 / BD 0.8 使用仓库已有的官方依赖本地镜像。尚未进行游戏内联机实测。
