# Beyond: Craftlines 0.7.3

以上一正式版本 0.7.2 为基线，修复仪表盘容器附着并补充失败原因提示。
适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2、26.2、26.3 NeoForge 的 BD 0.7 构建，以及 1.20.1、1.21.1 的 BD 0.8 专用构建。

### 主要更新

- 原版箱子、陷阱箱等实现原版库存接口的容器不再需要完整支撑面，即可附着仪表盘。完整支撑方块继续可用，空气、水、火把等无有效支撑的目标仍被拒绝。
- 尝试放置时，如果目标不满足附着条件，服务端向玩家发送动作栏提示：“无法放置仪表盘：目标表面需要完整支撑面或库存容器。”提示提供中英文翻译；方块日常生存检查不发送消息，其他原因的放置失败不会误报为支撑问题。
- 放置到箱子上仍使用 Shift＋右键；普通右键继续优先打开箱子。
- 五个 Minecraft 版本及两个 BD 0.8 构建统一更新为 0.7.3，网络协议继续使用 35，依赖范围保持不变。

自动回归使用真实原版箱子、陷阱箱方块状态和方块实体，覆盖六面附着、完整方块、无效支撑和移除箱子后的附着资格。尚未进行游戏内实机验收。

构建验证：七套 `build` 全部通过，共 2639 次测试执行，失败、错误、跳过均为 0。七个 JAR 已核验 ZIP 完整性、0.7.3 版本元数据、对应 Java 17 / 21 / 25 字节码及中英文动作栏提示资源。
