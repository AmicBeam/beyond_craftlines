# 动态合成与 BD 分包验收

## 支持矩阵

| MC | BD 0.7 | BD 0.8 | JDK |
|---|---|---|---|
| 1.20.1 Forge | `versions/1.20.1` | `versions/1.20.1-bd0.8` | 17 |
| 1.21.1 NeoForge | 根目录 | `versions/1.21.1-bd0.8` | 21 |
| 26.1.2 NeoForge | `versions/26.1.2` | 暂无 | 25 |
| 26.2 NeoForge | `versions/26.2` | 暂无 | 25 |
| 26.3 NeoForge | `versions/26.3` | 暂无 | 25 |

BD 0.7 产物有严格的 `<0.8` 上限；BD 0.8 产物最低 0.8.8，上限 `<0.9`。同一实例安装一个匹配的产物。0.8 使用 CompixelUI 页面扩展，不加载旧网络 GUI Mixin；供给器覆盖新版 admission 插入重载，客户端同步使用新版接口。Forge 构建共用 `gradle/forge-build.gradle`；Forge 0.8 的供给器保留 Forge capability/NBT 实现并补充客户端同步。其开发编译使用共同 API 基线 Forge 47.1.33，实际运行必须符合 BD 0.8 的 Forge 47.2.18 下限；如需开发启动，添加 `-Pforge_version=47.2.18` 或更高版本。

## 烟花执行边界

`FireworkRocketRecipeVariants` 从真实来源配方展开三条普通推进火箭变体；ID 包含来源配方、飞行时间和算法版本。规划输入明确保留重复火药槽位，不能把多个火药槽折叠为一个堆叠槽。预览和产量来自原版 `assemble`，执行也委托来源配方的 `matches`、`assemble`、`getRemainingItems`。生成的变体不写入原版 RecipeManager，也不使用客户端虚拟产物模板执行。

菜单、固定链复算、客户端目录及执行查询均能解析变体 ID；JEI 的原配方入口按完整目标键映射到对应变体。配方重载清理变体缓存，规划磁盘缓存升级为版本 5。实际产物在扣料前按完整 NBT/组件及单次产量校验。校验仅作用于烟花变体，未修改通用 `StackKeyMatch`、`slashblade.json` 或其他配方的运行时放宽策略。

首轮仅支持无烟火之星的普通火箭。带爆炸效果、额外自定义状态或不可精确匹配的目标不回退为普通火箭。

## 自动测试

七个构建均执行公共测试：

- `FireworkRocketVariantsTest`：使用原版火箭实际组装结果，检查三个飞行时间的独立输入槽、产量、组件身份、错误等级/产量拒绝，以及来源相关的稳定 ID。
- `BrewingIdentityTest`：使用实际药水栈，检查水瓶/粗制药水及普通/喷溅身份分离，未配置配方不放宽身份，以及三瓶批次规则。原版炼药仍走绑定的真实酿造台；此测试不假装执行机器 tick。
- `WhiteSheathOutputPolicyTest`：读取正式 `slashblade.json`，用真实 ItemStack 的刀状态组件夹具验证 JEI 模板与实际状态不同时仍由配置的白鞘生产步骤接受；无对应生产步骤及火箭/炼药配方不得借用此策略。该夹具不加载真实拔刀剑模组。
- `BdArtifactSelectionTest`：在七个组合中核对真实打包元数据的 BD 依赖范围及对应 UI 适配类，避免编译通过但接受错误 ABI 家族。
- BD 0.8 专属用例检查类链接、页面入口或存储插入重载；1.21.1 的存储测试实际验证新重载不能绕过订单投料限制。

测试环境限制：1.20.1 的普通 JUnit 无 Forge SRG 重映射加载器，因此对真实 NBT 栈使用实现 IStackKey 契约的测试桥，未声称直接运行生产 BD ItemStackKey。26.x 测试只初始化用例所需的共同物品默认组件，药水/刀状态由夹具赋值，烟花组件由原版 assemble 生成；不启动后台临时服务器。

## 游戏内验收

单元测试不等于已加载真实模组完成联机验收。交付报告必须单独说明是否执行以下项目：

1. 在七个构建组合中从网络菜单及 JEI 请求三种普通火箭，检查材料消耗、实际飞行时间、混合库存提取与交付；材料不足不得生成低等级替代品。
2. 绑定酿造台，验证水瓶到粗制药水到成品药水的真实生产链，含普通/喷溅/滞留区分、燃料与三瓶回收。
3. 加载对应版本拔刀剑，实际制作白鞘，并将真实武器用于下一步升级，确认状态保留、预留/投料/交付不被模板差异阻断。
4. BD 0.7 检查侧栏入口；BD 0.8 检查新页面入口、供给器客户端图标同步和非订单投料拒绝。
