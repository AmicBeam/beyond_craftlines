# 配方树的 🚫 候选（0.7.0）

Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.2 NeoForge 和 26.3 NeoForge 使用相同机制。

- 右键任意未满足库存的资源节点可以打开配方候选弹窗，第一项始终是 🚫。即使没有生产配方，弹窗也保留这一个选项。Shift + 右键仍优先打开原料候选；没有原料可选时打开配方候选。
- 🚫 表示不通过配方制造该资源，只使用当前库存。库存不足时，该资源本身列为缺料，不继续展开它的原料；库存足够时，父配方仍可制造。订单根目标选择 🚫 时不会转为直接提取现有目标库存。
- 点击 🚫 与点击其他配方一样，会保存为客户端偏好。后续回退搜索和最优搜索也保留此选择；使用“忘记偏好”恢复自动选择。偏好保存于 `config/beyond_craftlines-planner-preferences.json`，配方值为 `beyond_craftlines:no_recipe`。
- 自动展开遇到祖先重复时，在重复节点的上一级默认停为 🚫；玩家仍可在上一级右键选择实际配方。显式指定的配方保留其选择。具有正净产出的自增配方继续按种子机制处理。

客户端配置 `config/beyond_craftlines-client.toml` 的 `[planning]` 中新增 `showCyclicTreeNodes = false`。它只控制是否显示成环分支最底下的重复祖先标记，不控制 🚫 机制，不改变库存需求或配方执行。设为 `true` 时显示这个标记，便于检查循环。

🚫 使用程序绘制的红色禁止图标，以避免不同 Minecraft 字体缺少 emoji。原料候选弹窗保持原有选材机制。
