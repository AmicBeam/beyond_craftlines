# 0.7.4 槽位投料验收

本次主要更新：按槽位是否接受材料来投料，保留原配方空槽，并在同一订单内复用槽位兼容性判断。直连机器和合成链供给器均支持。

适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2、26.2、26.3 NeoForge，以及 1.20.1、1.21.1 的 BD 0.8 构建。动力合成器场景使用对应版本可用的 Create；用扳手将输入库存连成一组，网格宽度与配方一致，先确认手动摆料能够合成。

## 功能验收

1. **交错材料投料**：给一组 3×3 动力合成器下单一份，配方是 5 个 A、4 个 B 交错排列。检查九格实际摆放与配方一致，不会先填入所有 A，再填入所有 B；最终正常合成，材料消耗正确。

2. **跳过配方空槽**：选择包含开头空格、中间空格、整行空格和末尾空格的配方。检查材料没有向前挤占空格，空格仍为空，含盖板的动力合成器能正常完成配方。

3. **按接受性选择槽位**：使用槽位有不同接收限制的测试库存，例如槽 0 只收 B、槽 1 只收 A。按 A、B 顺序投料时，应分别进入槽 1、槽 0，不固定要求配方第一格进入机器第一槽。同一订单重复制作时复用兼容性判断，新订单重新检测；这一计数由 UT 验证。

4. **多份订单**：对交错配方一次下单多份，分别开启和关闭阻挡模式。每次仍按完整一份投料，前后批次不混格，最终产量和总消耗正确。

5. **供给器转发**：通过供给器重做交错配方和含空槽配方，确认缓存中的同种材料合并后，转发仍保持正确位置。连接两组动力合成器，并切换轮询、最近、最远和均分策略，确认一份配方不会被拆散到不同组。

## 相关回归

1. **普通机器投料**：单槽机器不能在同一轮被不同材料重复占用；普通非网格配方的批量投料和阻挡模式仍按原规则工作。

2. **投料受阻与取消**：让目标槽暂时无法接收，恢复后应继续补齐未完成材料，不乱塞其他格子、不重复扣料。中途取消时，供给器尚未发送的材料停止投送并退回网络，已进入机器的材料不重复返还。

3. **保存与重启**：在供给器已经缓存材料、或只投送了一部分时保存并重启。恢复后继续完成正确图案，不能重新发送已经成功投送的材料。

4. **JEI 缓存升级**：保留旧版 JEI 缓存，客户端和服务端一起更新 0.7.4，再打开含空槽配方。确认重新采集后的图案正确，退出重进后也不会丢失空槽。

## 当前验证状态

七套构建和 2722 次自动测试执行已通过，其中新增槽位 UT 为 11 项。上述游戏内场景待验收，动力合成器库存模型 UT 不代表真实 Create 实机验收已完成。
