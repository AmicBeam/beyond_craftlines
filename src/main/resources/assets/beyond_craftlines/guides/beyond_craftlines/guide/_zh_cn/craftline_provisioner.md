# 合成链供给器

<BlockImage id="craftline_provisioner" scale="1.5" float="right" />

合成链供给器是可配置的配方步骤端点，适合不应直接投入某一台绑定机器的场景。它只接收活动 Craftlines 订单产生的资源，管道不能向其中随意写入物品。

## 打开与配置

右击方块，或手持 <ItemLink id="network_linker" /> 左击方块，可打开配置界面。

先启用供给器应承接的配方类型，再按需选择每种类型下的材料组。不选择任何材料组时，该供给器是此配方类型的通配端点；显式材料组端点优先于通配端点。匹配等级相同时，再比较各端点的数值优先级。

清空全部配方类型会同时清空所有无线设备连接，避免供给器保留已经失效的路由。

## 库存与管道工作流

订单路由到供给器的资源会进入其库存，外部管道可以抽取并送往目标机器。只有完整的预期产物返回 Beyond Dimensions 网络后，订单才会继续完成。

当机器需要管网、过滤器或其他不应由 Craftlines 直接控制的运输层时，适合使用这种方式。

## 无线直接供应

使用 <ItemLink id="network_linker" /> 为远程设备指定供应面。供给器会通过该面公开的能力，将匹配的订单资源直接送入设备。

投送按钮可循环切换：

- **轮询**：依次轮换可用目标。
- **最近优先**：先尝试距离最近的目标。
- **最远优先**：先尝试距离最远的目标。

目标拒收当前资源时，供给器会继续尝试下一个符合条件的目标，而不是立即卡住。

## 请求期间抽取

远程设备还可以设置抽取面。只有本供给器参与当前合成请求时，抽取才会运行，并把受支持的产物从该面直接送入 Beyond Dimensions 网络；产物不会经过供给器库存。

同一设备可以同时拥有供应面和抽取面。每个供给器默认最多连接 16 台不同设备，服务端配置可以调整此上限。GUI 和 Jade 会分别显示供应与抽取数量。

## 如何选择路由方式

- 机器公开能力足够，且整步配方应由一台机器负责时，使用**直接绑定机器**。
- 希望由外部运输系统分配原料时，使用**供给器库存加管道**。
- 希望供给器自行选择多台远程目标时，使用**无线供应**。
- 希望同一供给器只在承接请求期间回收远程设备产物时，再增加**请求期间抽取**。
