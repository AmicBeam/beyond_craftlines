# 网络连接器

<ItemImage id="network_linker" scale="2" float="right" />

网络连接器用于将真实配方机器和合成链供给器关联到当前 Beyond Dimensions 网络。它不会替代机器自身的库存或配方逻辑：Craftlines 仍通过机器公开的能力投料，并等待机器实际产出。

## 直接绑定机器

1. **右击受支持的机器**，将它绑定到网络。
2. 手持连接器**左击已绑定机器**，配置其配方类型、材料组和优先级；创造模式下不会因此破坏机器。
3. 在供给器编辑模式外，**潜行右击已绑定机器**可解绑。

配方类型由 JEI 催化剂和服务端配方类型共同确定。Beyond Dimensions 网络组件（包括原生网络熔炉）不能绑定，因为 Craftlines 会直接调度它们。

该实验版始终走 JEI-only 链路，并把 JEI category UID 保存为运行时 family；不加载 RecipeType alias 或分类白名单。JEI 输入 slot name 会保留为供给器材料子标签，普通编号输入槽统一归入 `ingredients`。

如果一种配方公开多个逻辑材料组，不同端点可以分别负责不同组。显式选择材料组的端点优先于未筛选的通配端点；匹配等级相同时，配置数值更高的优先级先被选择。

## 让供给器识别配方类型

1. **潜行右击供给器**，将它选为配方扫描目标。
2. 用连接器操作人工配方目标；识别出的配方类型会加入供给器候选项。
3. 打开供给器，启用它应承接的配方类型和材料组。

只识别到一种配方类型时可自动选中。右击空气会退出当前连接器模式或清除当前选择。

原版酿造台公开真实库存能力，可以作为机器直接绑定。一次酿造按最多 3 个药水槽输入与 1 个材料输入处理，并产出 3 瓶药水；递归规划把它视为一个批次，不会再把每瓶输入扩大成一整批 3 瓶。锻造与切石使用服务端权威配方，默认由网络库存直接代理执行，无需锻造台或切石机；服务端可通过 `crafting.enableSmithingAndStonecuttingRecipeProxy` 关闭。铁砧与堆肥桶仍只能作为供给器目标。

## 供给器无线连接

供给器已有配方类型后，用连接器**右击供给器**进入无线连接编辑。

- **右击设备面**：设置或移动该设备的供应面。
- **潜行右击设备面**：设置或移动该设备的抽取面。
- 对已绑定面重复同一种操作，只会断开对应角色。
- 同一设备可以同时拥有两种角色，在供给器连接上限中仍只算一台设备。

编辑时，供应面及连线为蓝色，抽取面及连线为深橙色，准星指向的候选面为黄色。退出编辑后，已连接面显示持续的蓝黑超维边框；客户端配置可关闭该边框，但不会关闭编辑态高亮。

路由、抽取和投送策略详见 <ItemLink id="craftline_provisioner" />。
